# Mathan's Portfolio 🚀

Welcome to my personal 3D interactive portfolio! This project showcases my skills, experience, and projects as an AI Research Intern and Software Engineer, featuring an immersive 3D character experience built with React Three Fiber.

## 🌟 Features

- **Interactive 3D Character**: A fully rigged and animated 3D character exploring the portfolio built using `three` and `@react-three/fiber`.
- **Custom Physics & Collisions**: Integrated using `@react-three/rapier` and `@react-three/cannon`.
- **Dynamic Animations**: Smooth scrolling and reveal animations powered by `gsap` and `lenis`.
- **Chess Minigame**: A built-in chess engine integrated using `chess.js` and `stockfish.js`.
- **Responsive Design**: Carefully crafted pure CSS styling ensuring a beautiful experience across devices.
- **Modern Tech Stack**: Fast and optimized frontend built with React + Vite and TypeScript.

## 🛠️ Tech Stack

- **Framework**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **3D Rendering**: [Three.js](https://threejs.org/), [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber/), [@react-three/drei](https://github.com/pmndrs/drei)
- **Physics**: `@react-three/rapier`, `@react-three/cannon`
- **Animations**: [GSAP](https://gsap.com/), [Lenis](https://github.com/studio-freight/lenis) (Smooth Scroll)
- **Icons**: `lucide-react`, `react-icons`

## 🚀 Running Locally

To run this project on your local machine, follow these steps:

### Prerequisites
Make sure you have Node.js installed. (v16 or higher is recommended)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mathan527/_portfolio_.git
   cd _portfolio_
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173/` to view the application.

## 🏗️ Building for Production

To build the project for production, run:
```bash
npm run build
```
This will compile the TypeScript code and output the optimized build to the `dist` folder.
